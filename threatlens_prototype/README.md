# ThreatLens Prototype

Open `index.html` in a browser to start.

## Pages
- index.html — Landing page
- login.html — Student/Teacher profile selection
- dashboard.html — Personalized dashboard
- learn.html — Phishing, Privacy, Cyberbullying learning modules
- mission.html — Interactive scenario with AI hint
- quiz.html — Interactive quiz
- coach.html — AI CyberCoach
- badges.html — XP, levels and badges
- join-class.html — Student class-code flow
- teacher.html — Teacher/class analytics

## Shared files
- style.css — all styling
- app.js — shared navigation, localStorage profile, XP, quiz, scenario and AI demo logic

## Demo
1. Open index.html.
2. Click Start Learning.
3. Enter your own name and choose Student or Teacher.
4. Continue to the dashboard.
5. Try Learn, Mission, Quiz, AI Coach and Badges.
6. Use class code `CSE2A-7K42` on Join Class.
7. Teacher dashboard is available if you selected Teacher.

No backend is required for this prototype. User input and progress are stored in browser localStorage.
